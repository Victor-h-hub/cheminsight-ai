# Uso da IA no Desenvolvimento

## Objetivo deste documento

Este documento descreve de forma transparente como ferramentas de Inteligência Artificial foram utilizadas durante o desenvolvimento do projeto **AI Data Insights Dashboard**, apresentado como parte de um processo seletivo para a área de tecnologia e dados.

O objetivo é demonstrar quais atividades contaram com apoio de IA, quais decisões permaneceram sob responsabilidade do desenvolvedor e como o uso dessas ferramentas contribuiu para acelerar o aprendizado e a construção do MVP.

---

# Contexto do projeto

O projeto foi desenvolvido por um estudante iniciante em Python, com tempo limitado para execução e entrega.

Diante desse cenário, a Inteligência Artificial foi utilizada como ferramenta de apoio técnico e educacional, permitindo acelerar o aprendizado de conceitos, compreender tecnologias utilizadas no projeto e reduzir o tempo necessário para implementação de funcionalidades.

O uso da IA foi encarado como um processo de colaboração e aprendizado, e não como substituição da tomada de decisão humana.

---

# Ferramentas utilizadas

Durante o desenvolvimento foram utilizadas diferentes ferramentas de IA generativa, incluindo:

* ChatGPT
* Claude
* Google Gemini

Cada ferramenta foi utilizada em momentos específicos para comparação de soluções, revisão de código, esclarecimento de dúvidas e apoio à documentação.

---

# Como a IA foi utilizada

## 1. Aprendizado acelerado

A IA foi utilizada como apoio educacional para compreender conceitos que eram novos para o desenvolvedor, incluindo:

* Estruturação de projetos Python
* Modularização de código
* Uso de Streamlit
* Manipulação de dados com Pandas
* Integração com APIs
* Uso de variáveis de ambiente
* Boas práticas básicas de desenvolvimento

Além de fornecer respostas, a IA foi utilizada para explicar conceitos, justificar decisões técnicas e detalhar o funcionamento do código gerado.

---

## 2. Construção de funcionalidades

A IA auxiliou na implementação de funcionalidades do sistema, incluindo:

* Upload de arquivos CSV
* Leitura e validação de dados
* Geração de estatísticas descritivas
* Criação de gráficos com Plotly
* Integração com a API Gemini
* Exibição de insights gerados por IA
* Tratamento básico de erros

O código sugerido pela IA foi analisado, adaptado e integrado à estrutura definida para o projeto.

---

## 3. Revisão e melhoria de código

A IA também foi utilizada para:

* Identificar possíveis erros
* Revisar trechos de código
* Sugerir melhorias de legibilidade
* Avaliar organização do projeto
* Apontar redundâncias e simplificações

Nem todas as sugestões foram aceitas, sendo avaliadas individualmente de acordo com os objetivos do MVP.

---

## 4. Compreensão da arquitetura

Além de gerar código, a IA foi utilizada para explicar:

* Fluxo de execução do sistema
* Responsabilidade de cada módulo
* Comunicação entre arquivos
* Papel do Streamlit no projeto
* Papel do Pandas na análise dos dados
* Fluxo de dados até a geração dos insights

Esse processo permitiu que o desenvolvedor compreendesse melhor a arquitetura construída e fosse capaz de explicar e defender as decisões adotadas.

---

# Decisões conduzidas pelo desenvolvedor

Embora a IA tenha sido amplamente utilizada como ferramenta de apoio, as principais decisões do projeto foram conduzidas pelo desenvolvedor.

Entre elas:

## Escopo do produto

Definição de:

* objetivo do sistema;
* público-alvo;
* funcionalidades prioritárias;
* limitações aceitas para o MVP.

---

## Arquitetura do projeto

Decisões relacionadas a:

* separação em módulos;
* criação da pasta `utils`;
* organização dos arquivos;
* responsabilidades de cada componente.

---

## Experiência do usuário (UX)

Definições como:

* simplicidade da interface;
* organização das informações;
* uso de gráficos;
* inclusão de insights automáticos;
* criação de botão para disparar a análise da IA apenas quando desejado.

---

## Funcionalidades implementadas

A escolha das funcionalidades presentes no MVP foi realizada pelo desenvolvedor, incluindo:

* upload de CSV;
* visualização tabular;
* estatísticas descritivas;
* gráficos;
* insights automáticos;
* insights com IA.

---

# Validação das respostas da IA

As respostas geradas pelas ferramentas de IA não foram aceitas automaticamente.

Sempre que possível foram realizadas:

* verificações manuais;
* testes de execução;
* comparação entre diferentes modelos de IA;
* ajustes de código;
* simplificações para adequação ao escopo do projeto.

Esse processo foi importante para evitar dependência excessiva das sugestões geradas automaticamente.

---

# Limitações observadas

Durante o desenvolvimento foram identificadas algumas limitações do uso de IA:

* Sugestões ocasionais de soluções excessivamente complexas para o estágio do projeto;
* Uso de bibliotecas ou métodos desatualizados em alguns casos;
* Necessidade de validação constante das respostas;
* Diferenças de qualidade entre modelos para tarefas específicas.

Essas limitações reforçaram a importância do senso crítico humano durante todo o processo.

---

# Considerações finais

A Inteligência Artificial teve papel relevante no desenvolvimento deste projeto, principalmente como ferramenta de aprendizado, apoio técnico e aceleração da execução.

Entretanto, a definição do problema, a concepção da solução, as decisões de produto, as decisões de arquitetura, a experiência do usuário e a validação das funcionalidades permaneceram sob responsabilidade do desenvolvedor.

O uso da IA foi realizado de forma transparente, consciente e alinhada ao objetivo de ampliar produtividade e aprendizado, mantendo a responsabilidade humana sobre as decisões finais do projeto.
